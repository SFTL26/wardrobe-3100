# Шкаф в прихожую 3100 × 3100 × 500

Пошаговая инструкция по сборке открытого шкафа из готовых белых деталей ЛДСП
Лемана ПРО для коридора модульного дома DUBLDOM DUB 138 (стена «Вид 1»).

- **[index.html](index.html)** — сама инструкция, один файл. Открывается в любом
  браузере. Для 3D нужен интернет: библиотека three.js грузится с cdnjs.
- **[instruction.pdf](instruction.pdf)** — то же для печати, 3D-шаги картинками.

## Что внутри

Конструкция: 2 модуля по 1550 мм и 2 антресоли по 400 мм, без задней стенки.
Жёсткость дают царги 1550×100, шкаф крепится через них к стойкам каркаса.

- проверка ниши и стен, план коридора
- закупка с артикулами Лемана ПРО (детали, крепёж, инструмент)
- карты распила (только поперечные резы, детали от 25 см) и блок для стойки распила
- сверление: конфирматы и полкодержатели кондуктором МК-20 (сетка 32 от нижнего торца)
- сборка модулей и антресолей, установка, крепление к каркасным стенам
- три 3D-анимации: сборка по шагам, сверление крупным планом, «из распила в шкаф»
  (обозначения деталей Б, Г, П1–П4, Р, А, Ц, можно скрыть)

Детали: 17 × 2700×500×16 (арт. 82036041) и 4 × 2700×100×16 (арт. 82124609).

## Как пересобрать

Нужен только Python 3, без библиотек.

```
python src/build.py
```

Скрипт собирает `index.html` из частей в `src/`:

| Файл | Что в нём |
|---|---|
| `template.html` | стили и весь текст инструкции с плейсхолдерами `{{...}}` |
| `svgs.py` | чертежи: вид спереди, карты распила, разметка боковин, узел крепления, план коридора |
| `v3d.html` / `v3d.js` | 3D-сборка по шагам |
| `drill.html` / `drill.js` | 3D-сверление (конфирматы, кондуктор МК-20) |
| `asm.html` / `asm.js` | 3D «из распила в шкаф» |

Размеры заданы в нескольких местах: тексты в `template.html`, геометрия в `svgs.py`
и в трёх js-файлах. При изменении высот или длин деталей править везде.
